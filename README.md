# Skyrim Takeover

**Terraria** × Skyrim · visual · idea by the team

Bring Skyrim into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> Skyrim Takeover: snow, draugr, gossiping guards and a dragon you fight with Fus Ro Dah. The cheese wheel bowling was an accident.

## Install

Copy Sigf.tmod into Documents/My Games/Terraria/tModLoader/Mods, enable it in tModLoader's Mods menu, then load any world. It snows around spawn, draugr and guards appear, and a dragon arrives soon after.
